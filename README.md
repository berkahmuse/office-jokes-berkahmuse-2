## The joke

> We replaced the weekly meeting with an email, then scheduled a meeting to discuss why nobody read the email.

## How it works

`main.py` is a deterministic program that writes the one-line office joke above
to `/output/entry.txt`. Nothing else is written; the output is a single line of
under 200 characters.

Run it locally (the grader sandbox writes to `/output`):

```sh
python3 main.py
```
